# SuccessLabs Academy — 108 Learning Experience Formats

**Mission:** Architecting Experiences for a Better World.

**Status:** Proposed master taxonomy for review; this coaching crosswalk is published, but the complete 108-row master table has not been verified here.

**Code convention:** Numeric IDs `101–208` are permanent; three-letter mnemonic codes are unique.

**Scope:** Human Resources (HR), Customer Experience (CX), Finance, Procurement, Supply Chain Management (SCM), Business Transformation Management (BTM), and Leadership & Identity Transformation.

**Duration:** Suggested learner contact/practice time unless days or weeks are specified; adjust for skill level and complexity.

**Design principle:** Formats identify the *learning mechanism*, not the topic, delivery channel, platform, or membership tier. A course may combine formats, but each activity should have one primary format.


Canonical format identifiers: numeric 101–208 and three-letter mnemonic codes. **Keep existing folder names and URLs stable**; add the mnemonic in brackets in titles and directory index labels.

- Display titles: `Bootcamp [BCP]`, `Challenge (21-Day) [CHL]`.
- New folder naming (optional): `105-BCP-bootcamp`.
- **Do not rename existing directories** without updating all incoming links, catalog generators, and LMS references.

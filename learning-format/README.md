# SuccessLabs Academy — 108 Learning Experience Formats

**Mission:** Architecting Experiences for a Better World.  
**Status:** Proposed master taxonomy for review; published to the SuccessLabs Academy coaching GitHub repository.  
**Code convention:** Numeric IDs `101–208` are permanent; three-letter mnemonic codes are unique.  
**Scope:** Seven enterprise learning domains: Human Resources (HR), Customer Experience (CX), Finance, Procurement, Supply Chain Management (SCM), Business Transformation Management (BTM), and Leadership & Identity Transformation.  
**Duration:** Suggested learner contact/practice time unless days or weeks are specified; adjust for skill level and complexity.  
**Design principle:** Formats identify the *learning mechanism*, not the topic, delivery channel, platform, or membership tier. A course may combine formats, but each activity should have one primary format.

## Differentiation and implementation rules

1. **No synonym codes:** Keep distinct evidence and facilitation mechanics. For example, `DGN` isolates the next diagnostic step, `RCA` proves causation, and `DFX` repairs a confirmed defect.
2. **Practice evidence:** Every applied format should end with an observable artifact, decision log, execution record, rubric score, or behavior demonstration.
3. **Cross-domain reuse:** Keep the format code constant when switching from HR to CX, Finance, Procurement, SCM, BTM, or Leadership & Identity Transformation.
4. **Composition:** A `BCP` bootcamp may contain `LAB`, `TST`, `RPL`, and `REV` activities; these are distinct activity types, not duplicate course titles.
5. **Governance:** Preserve all permanent numeric IDs `101–208` and their existing three-letter codes. Validate ID continuity, letter-code uniqueness, and all required fields before publishing any registry revision.
6. **Duration:** These are design estimates, not certification, regulatory, or platform requirements. For extended formats, distinguish calendar duration from actual contact hours.
7. **Identifiers:** Example `GICS01-HR07-BCP-105-FND-001` combines sector, theme, format mnemonic, numeric code, level, and edition.

# Additional Learning Formats — 209+

This folder is reserved for learning experience formats **after** the established 108 entries (numeric codes 101–208). Code 208 belongs to the existing registry.

## Admission criteria

1. The new format must have a distinct learning mechanism and demonstrable practice outcome.
2. It must not duplicate any of the existing 108 formats.
3. Assign the next unused numeric code (209 onward) and a unique three-letter mnemonic.
4. Document **what it is**, **what it is not**, **suggested duration**, **enterprise application example**, and **evidence of learning**.
5. Preserve numeric and mnemonic identifiers after publication.
